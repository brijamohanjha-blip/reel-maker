# ReelStudio

Remotion engine for 30-50 s vertical Reels (1080x1920, 30 fps): voiceover + AI-generated clips + word-by-word captions + end card. Driven by the `reel-maker` skill (`~/.claude/skills/reel-maker/SKILL.md`), which holds the full workflow.

## Layout

- `jobs/<slug>/` — plan.json (beats, prompts), script.txt (exact ElevenLabs text), whisper.json (raw transcript)
- `public/jobs/<slug>/` — voiceover.mp3, clips/scene-<id>.mp4, captions.json (aligned)
- `reels/<slug>.json` — generated by `scripts/build-reel.mjs`; can be hand-tweaked
- `out/<slug>.mp4` — final render

## Commands

- Transcribe: `node scripts/transcribe.mjs public/jobs/<slug>/voiceover.mp3 <hi|en> jobs/<slug>/whisper.json`
- Align to script: `node scripts/align-captions.mjs jobs/<slug>/whisper.json jobs/<slug>/script.txt public/jobs/<slug>/captions.json`
- Build reel JSON: `node scripts/build-reel.mjs <slug>`
- Preview: `npx remotion studio --props=reels/<slug>.json`
- Stills: `npx remotion render Reel out/stills-<slug> --sequence --image-format=png --frames=0,90,... --props=reels/<slug>.json`, then `node scripts/contact-sheet.mjs out/stills-<slug> out/stills-<slug>.png`
- Render: `npm run render -- reels/<slug>.json` → `out/<slug>.mp4` (frames via Remotion, encoded with ffmpeg-static because Remotion's bundled ffmpeg needs macOS 15+)

Never hardcode Reel content in components. Everything content-specific belongs in the JSON.

## Rules (always apply)

- Keep all text inside the 120px top and bottom safe margins.
- No end card by default: the disclosure ("AI voice used. Not medical advice.") goes in the Instagram caption. Set `"endCard": true` in plan.json only if the user wants it in the video (`endCardText` changes the wording).
- No medical claims such as "cures" or "removes permanently"; hedge ("ho sakta hai", "maana jaata hai", "may help"). No dosages, no result promises.
- Never show an AI person giving a personal testimonial. No faces of real people, no brand packaging or logos, no before/after visuals, no bald scalp.
- No music unless the user asks.
- A Reel isn't ready to post until the user has fact-checked every claim in the fact sheet.
